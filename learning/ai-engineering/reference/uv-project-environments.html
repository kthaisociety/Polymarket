The uv environment map

Intent · pyproject.tomlPermitted Python and direct dependencies; human-managed.
Resolution · uv.lockExact resolved graph; commit it and let uv manage it.
Reality · .venv/Disposable installed environment; do not commit it.

Version-control rule

commit: pyproject.toml, uv.lock, .python-version (if used)
ignore: .venv/
Boundary: package locking does not freeze the OS, data, APIs, model behavior, seeds, or source revision.
