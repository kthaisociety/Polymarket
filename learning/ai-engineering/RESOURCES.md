# AI Engineering Resources

## Knowledge

- [AI Hero: The AI Engineer Roadmap](https://www.aihero.dev/ai-engineer-roadmap)
  Matt Pocock's overview of model selection, the AI-engineering mindset, evals, and improvement techniques. Use for: the course's external conceptual spine.
- [AI Hero: AI Skills for Real Engineers](https://www.aihero.dev/skills)
  The philosophy and workflow behind small process skills whose outputs feed one another. Use for: deciding when a reusable agent skill is earned.
- [AI Hero: Learn Anything With My /teach Skill](https://www.aihero.dev/learn-anything-with-my-teach-skill)
  The source workflow for mission-driven lessons, interactive exercises, and persistent learning records. Use for: maintaining this learning system.
- [Repository README](../../README.md)
  The product objective, reading order, and source-of-truth hierarchy. Use for: orienting every repository-specific lesson.
- [Repository instructions](../../AGENTS.md)
  The durable working agreement and non-negotiable engineering rules. Use for: translating architecture into day-to-day behavior.
- [Architecture specification](../../docs/specification/ARCHITECTURE.md)
  The intended end-to-end topology, feedback loops, and boundaries. Use for: architecture lessons after repository orientation.
- [Decisions](../../docs/specification/DECISIONS.md) and [Invariants](../../docs/specification/INVARIANTS.md)
  Locked choices, deferred choices, and rules implementation must preserve. Use for: learning how specifications constrain code without overdetermining it.
- [Test strategy](../../docs/specification/TEST_STRATEGY.md)
  The repository's verification philosophy. Use for: evals, contract tests, scientific tests, and agent behavioral evaluation.
- [uv: Locking and syncing](https://docs.astral.sh/uv/concepts/projects/sync/)
  Astral's official explanation of resolution, lockfiles, exact syncing, and automatic syncing before `uv run`. Use for: reproducible Python environments and CI setup.
- [uv: Project structure and files](https://docs.astral.sh/uv/concepts/projects/layout/)
  Astral's official description of `pyproject.toml`, `uv.lock`, and the project environment. Use for: understanding which project artifact owns which dependency concern.
