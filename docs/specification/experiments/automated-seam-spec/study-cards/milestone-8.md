## evaluation.grade-research-behavior — scenario state/actions/evidence/traps + provider → graded behavioral outcome

**Why does it exist?** Establish whether the composed agent—not just local plumbing—respects research, retrieval, recovery, authority, commit and scientific-evidence behavior.

**Which fundamental does it protect?** `CONSISTENT`: the seam honestly separates deterministic causality from stochastic reasoning quality.

**What must cross?** Scenario/version, provider/config/seed, available info/actions, trace/effects, grader rules/results, budgets, artifacts.

**Most dangerous false success?** Call a context-independent scripted sequence “autonomous reasoning.”

**Which test catches it?** For causal scenarios use Level C paired interventions/sentinel; for reasoning quality use repeated Level D property graders; adversarially delete context and inject traps.

**Any unresolved human decision?** None; per-scenario success thresholds remain human-owned before execution.
